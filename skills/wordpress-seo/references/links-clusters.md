# Topic clusters, links internos e links externos

## Topic Clusters

Estrutura:
```
PILLAR / CORNERSTONE
  → CLUSTERS
    → SUBTEMAS
      → CATEGORIAS
      → PRODUTOS/SERVIÇOS
```

Antes de marcar uma página como cornerstone, avalie:
- Centralidade temática real (é o hub do assunto, não só um artigo importante).
- Abrangência (cobre o tema de forma ampla o suficiente para linkar para os clusters).
- Função de pilar na arquitetura de links (recebe e distribui autoridade).
- Relação clara com os conteúdos específicos que dependem dela.

**Não marque cornerstone só porque o artigo é longo ou "importante".**

Planeje os links entre pilar ↔ clusters ↔ subtemas explicitamente, não apenas o conteúdo isolado.

## Links internos

Não adicione links só para satisfazer o Yoast. Avalie:
- Relevância semântica real entre origem e destino.
- Qualidade da página de destino (ela realmente ajuda o leitor aqui?).
- Âncora descritiva e natural (não genérica tipo "clique aqui").
- Contexto — o link deve fazer sentido na frase, não ser forçado.
- Profundidade de clique (páginas estratégicas não devem ficar a muitos cliques da home).
- Cobertura de categorias, produtos, serviços e artigos relevantes.
- Páginas órfãs — identifique e corrija.

**Links reversos**: depois de publicar um conteúdo novo, identifique quais páginas antigas deveriam passar a apontar para ele (não é só link de saída, é também quem deveria linkar para dentro).

Sugestões automáticas do Yoast (link suggestions) são **candidatas**, nunca ordens — avalie cada uma pelos critérios acima antes de aceitar.

## Links externos

Adicione apenas quando tiverem função editorial real (sustentar uma afirmação, referenciar dado, apontar para documentação). Priorize, conforme o assunto:
- Fontes primárias
- Órgãos oficiais / reguladores
- Universidades / literatura científica
- Documentação oficial
- Fontes institucionais confiáveis

Em temas YMYL, eleve o rigor — ver `eeat-ymyl-compliance.md`.

**Nunca insira link externo só para o Yoast ficar verde.**
